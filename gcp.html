CORE SERVICE

Cloud Run

The first major GCP service used in the Omkar Labs environment.

Why Cloud Run?

Cloud Run allows containerized applications to be deployed without managing traditional virtual machines.

Cloud Run provides a unique HTTPS endpoint for each service and can automatically scale based on incoming requests.

Important Concept

The application container must listen on the port supplied through the PORT environment variable.

The default Cloud Run container port is 8080.

REAL-WORLD LEARNING

Troubleshooting Cloud Run

Problems are part of the lab. Every failure becomes a learning opportunity.

LESSON #001

Container failed to start

One of the first Cloud Run challenges was a container that failed to listen on port 8080.

This highlighted the importance of ensuring the application listens on 0.0.0.0 and the correct PORT.

DEBUGGING

Check the logs

Cloud Run revision logs are one of the most important tools for identifying container startup and application errors.

The objective is not simply to make the deployment work, but to understand why it failed.
